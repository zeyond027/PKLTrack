# PKLTrack

Website dokumentasi PKL interaktif.

## Fitur
- Dashboard progres PKL
- Catatan kegiatan harian
- Upload foto dokumentasi
- Status kegiatan
- Daftar kompetensi dan progres
- Export laporan PDF
- Database SQLite

## Cara menjalankan

1. Install Python 3.
2. Buka terminal di folder proyek.
3. Buat virtual environment:

```bash
python -m venv venv
```

Windows:
```bash
venv\Scripts\activate
```

Linux/macOS:
```bash
source venv/bin/activate
```

4. Install library:

```bash
pip install -r requirements.txt
```

5. Jalankan:

```bash
python app.py
```

6. Buka browser:
http://127.0.0.1:5000
